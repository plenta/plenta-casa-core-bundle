# Plenta Casa

Plenta Casa is an open-source real estate solution for Contao CMS.  
It allows you to manage, import and display real estate listings directly in Contao 5.7 and above.

## Features

- Real estate management directly in the Contao backend
- Flexible list view with LiveComponent filter (Symfony UX)
- Detail view with configurable reader parts
- OpenImmo import (ZIP, XML)
- Map integration (Leaflet/OpenStreetMap)
- Schema.org / JSON-LD for real estate (RealEstateListing)
- Energy certificate display
- Contact management
- Multilingual support (de, en, fr, pl)
- Symfony UX LiveComponents for reactive filtering without page reload
- Twig-based templates (fully overridable)
- And much more

## Installation

```bash
composer require plenta/plenta-casa-core-bundle
```
